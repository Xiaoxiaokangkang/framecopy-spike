# 测试清单

## 自动检查

```bash
npm run check
```

当前自动测试覆盖：

- 逐字动画仅保留最终状态；
- 轻微 OCR 差异的相似度；
- 人工修改内容进入时间戳 Markdown。

## 手动端到端测试

1. 启动网页，健康检查为正常。
2. 上传一条 30—60 秒、小于 20 MB 的 MP4。
3. 确认任务经过检查、分析、识别、合并、生成五个阶段。
4. 确认结果页能显示段落、置信度和关键帧。
5. 修改一个段落，刷新页面，确认修改已保存。
6. 下载纯净版和时间戳版 Markdown，确认内容与页面一致。
7. 点击恢复自动结果，确认人工修改被恢复。

## 黄金样例分类

后续建立测试集时，至少覆盖：逐字、逐行、淡入淡出、快速闪现、黑底白字、复杂背景、中英混排、图表、小字脚注、多栏排版、横屏和竖屏。

每个失败样例记录：

- 任务编号；
- 视频时间点；
- 预期文字和实际文字；
- 错误类型：漏检、错字、重复、顺序、动画中间态或无关文字；
- 对应关键帧。
